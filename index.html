01 / EXAMPLE

ことばから、動く図へ。

研究背景を説明する、実際のスライドとプロンプト例。
図の配置と変化を、文章で指定します。

OUTPUT / 研究背景
最初の状態から最後まで、繰り返し再生スライドで見る ↗
INPUT / プロンプト例
1. 研究背景
   社会にある実問題から　組合せ最適化の概念を導入。

html --
左右で2つの問題例をだす。それぞれのアニメーションの下に
決めるもの、制約、目的　を書く。
左側　配送経路
四角の中に倉庫一つと家みたいなのを複数個用意、
倉庫から線が伸びて経路が作られるのを模擬。
右側　何か物の加工順
JSPかFSSPみたいな問題を例示。
作るもの3つで、作業機械3つ　A,B,Cで
作るものはそれぞれ　作業をもち、色でわかる感じ。
横軸時間、縦軸機械
いい感じに順番に詰め込まれていく。
待ち時間的なことをやったりして単調にならないように。
--

左は output/nco-intro.html の「研究背景」1枚を抽出したHTMLです。元の図と遷移を使い、この展示では自動でループ再生します。プロンプトは制作指示の例で、完成版には引用と説明文も加えています。

02 / WORKFLOW

見せたい変化を、順番に書く。

01

何を伝えるか決める

対象読者と結論、説明の順番をメモにします。「配送と加工順から、組合せ最適化を導入する」のように目的を具体的に。

02

配置と動きを指定する

左右の役割、図に置くもの、最初の状態、次に変わるもの、最後の状態を書きます。数・色・軸・制約も指定すると伝わります。

03

生成して、確かめる

AIにメモと制作ルールを渡し、QMDとHTML図を作成。ビルド後に動きと文字の重なり、PDFの最終状態を確認します。

git clone https://github.com/murata-lab/quarto-html.git
cd quarto-html
uv sync
uv run playwright install chromium
uv run scripts/slides.py build nco-intro

手元で試す

Quarto CLIとuvを用意して実行します。出力はアニメーションを内包した単一HTMLと、各ページの最終状態を収めたPDFです。

03 / GITHUB PAGES

動くデモを公開

HTML・CSS・JavaScriptを配信できるので、スライド、ループするアニメーション、操作できる図をそのまま公開できます。

制作環境と分ける

このサイトは専用の gh-pages ブランチに置いています。通常のcloneで開く main には、サイトのファイルが混ざりません。
